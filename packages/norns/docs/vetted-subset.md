# Vetted Civet/Pug subset (generated code)

The generator only emits constructs from this subset. Every construct here is proven
safe against the documented preprocessor traps (see NORNS.md "traps" sections); the
regression suite in `tests/vetted-subset.test.js` asserts that no generated file —
golden tree or fresh `generateApp()` output — ever contains a trap pattern, and
`selfCheck` (K-14) civet-compiles every pending file before anything is written.
Hand-written code in `src/` can hit preprocessor quirks; generated code cannot,
by construction.

## Civet subset (`.c` files)

Allowed constructs — nothing outside this list may be emitted:

| Construct | Example |
| --- | --- |
| Header comment | `// GENERATED by \`norns generate\` from specs/orders.tron — do not edit.` |
| Namespace imports | `import * as dz from 'drizzle-orm'`, `import * as v from 'valibot'` |
| Named imports (no Civet keywords) | `import { eq } from 'drizzle-orm'` |
| Default imports | `import priceBody from '$custom/orders/actions/price.c'` |
| Const declaration | `export submit := { … }`, `ops := { … }` |
| Object literals, quoted keys where needed | `{ 'and': dz.and, eq: dz.eq }` |
| Arrow functions (JS-style bodies, braces + `return`) | `run: async ({ input, container, user }) => { … }` |
| `const` / `if` / `throw` / `await` statements | `const db = container.resolve('db')` |
| Template literals | `` dz.sql`1 = 1` `` |

Forbidden — each is a documented trap:

| Trap | Why | What the generator does instead |
| --- | --- | --- |
| `isnt` | Compiles to a bare identifier reference → runtime `ReferenceError` | `!==` |
| `and` / `or` / `not` in brace imports | Civet operator keywords — parse error (unquoted object keys currently compile, but stay quoted defensively; pinned in norns-core C-01) | `import * as dz from 'drizzle-orm'` + quoted keys `'and': dz.and` |
| `async *name(` method shorthand | Historically rejected by the Civet parser; compiles under 0.11.16 (pinned in norns-core C-01) — excluded to keep the subset minimal | never emits generator methods |
| Indentation-style bodies for emitted functions | Whitespace sensitivity is fragile under string templating | JS-style braces + explicit `return` |

## Pug subset (`.n` files)

Template lines:

| Construct | Example |
| --- | --- |
| Plain tags + simple class shorthand (`[a-z-]` only) | `section.norns-page` |
| Component tags with attributes | `Kanban(data!="{data.board}" onMove="?/submit")` |
| Svelte-expression attributes via `!=` | `data!="{data.board}"` |
| `+if` / `+each` mixins — `+each` argument always contains ` as ` | `+each('data.rows as row')` |

Script block (single trailing `<script>`):

| Construct | Example |
| --- | --- |
| Props destructure with `:=` (const), never reassigned | `{ data, form } := $props()` |
| Local state with `:=` only when never reassigned | `selected := $state(null)` |

Forbidden — each is a documented trap:

| Trap | Why | What the generator does instead |
| --- | --- | --- |
| Markup snippets (`+snippet(…)` / `{#snippet}`) | Snippet TDZ: `<script>` runs before markup binds; referencing snippets from script throws | no snippets in generated pages; composition happens in components |
| Class shorthand containing `:`, `/`, or fractions (`.gap-2.5`) | Pug parses `:` as filter delimiter, `.5` as a new class (norns-core's class rewriter rescues these — pinned in C-01 — but the generator stays in the plain subset) | only `[a-z0-9-]` class shorthand; anything else goes in `class=""` attribute form |
| `+each('x of xs')` | svelte-preprocess maps the argument verbatim into `{#each …}` — it must be the full `as` expression | `+each('xs as x')` |
| `$bindable()` props | Requires `.= $props()` (`let`); `:=` compiles to `const` → "Cannot bind to constant" | generated pages never take bindable props, so `:=` is always safe |
| Pug interpolation `#{expr}` | Evaluates at preprocess time, not runtime | Svelte `{expr}` |
| Leading `{#…}` / `{@…}` / `{:…}` on a template line | Pug parses leading `{` as a tag | `+if` / `+each` mixins (or `| ` pipe text) |

## Enforcement layers

1. **Emitters** (`src/kernel/emit-*.js`) — construct output exclusively from the subset above.
2. **selfCheck** (`src/kernel/generate.js`) — civet-compiles every pending `.c` file and `.n` script block before any write; failure refuses generation with `SELFCHECK_FAILED` at the offending unit address.
3. **Regression suite** (`tests/vetted-subset.test.js`) — trap-pattern scan + `nornsLint` over the golden generated tree and fresh generator output; a new emitter cannot introduce a trap without failing CI.
